## 1. 텍스트 데이터를 모델에 적용하기 전 전처리 과정

자연어 처리(NLP)에서 모델이 텍스트를 잘 이해할 수 있도록 학습 전에 다음과 같은 일련의 전처리 과정을 거칩니다.

* **정제 (Cleaning):** 데이터에서 분석에 방해되는 노이즈(HTML 태그, 특수문자, 의미 없는 기호 등)를 제거합니다.
* **토큰화 (Tokenization):** 주어진 텍스트를 의미를 가진 최소 단위(단어, 형태소, 서브워드 등)인 '토큰(Token)'으로 나눕니다. 최근에는 단어를 더 잘게 쪼개는 서브워드(Subword) 토큰화(예: BPE, WordPiece)를 주로 사용합니다.
* **정규화 (Normalization):** 표현 방법이 다른 단어들을 통합시켜 같은 단어로 만들어줍니다. (예: 대소문자 통합, 'am/are/is'를 'be'로 통일하는 표제어 추출 및 어간 추출).
* **불용어 제거 (Stopword Removal):** 문장 내에서 자주 등장하지만 문맥적 의미를 파악하는 데 큰 도움이 되지 않는 단어(예: 은, 는, 이, 가, a, the 등)를 제거합니다.
* **정수 인코딩 및 패딩 (Integer Encoding & Padding):** 텍스트를 컴퓨터가 처리할 수 있도록 각 토큰을 고유한 정수로 맵핑하고, 병렬 처리를 위해 문장의 길이를 동일하게 맞추는 패딩 작업을 수행합니다.

## 2. FastText와 Word2Vec의 차이점 및 장점

두 모델 모두 단어를 벡터로 임베딩하는 기법이지만, 단어를 바라보는 단위(Unit)에 근본적인 차이가 있습니다.

* **차이점:** **Word2Vec**은 '단어(Word)' 자체를 최소 단위로 보아 하나의 단어를 하나의 벡터로 만듭니다. 반면, **FastText**는 단어를 '서브워드(Subword, 문자 단위의 n-gram)'들의 조합으로 취급합니다. 예를 들어 'apple'을 3-gram으로 나누면 `<ap, ppl, ple, le>` 와 같이 쪼개어 학습합니다.
* **장점:**
* **OOV(Out-Of-Vocabulary) 문제 해결:** Word2Vec은 학습 데이터에 없던 단어(OOV)가 등장하면 벡터를 생성할 수 없습니다. 하지만 FastText는 모르는 단어라도 내부의 서브워드 n-gram 벡터들을 조합하여 임베딩 벡터를 유추할 수 있습니다.
* **오탈자(Typo)에 강함:** 단어의 철자가 조금 틀리더라도 겹치는 서브워드가 많기 때문에 원래 단어와 유사한 벡터를 얻을 수 있습니다.
* **교착어 처리에 유리:** 한국어처럼 형태소가 다양하게 결합하는 언어에서 풍부한 형태론적 특징을 잘 잡아냅니다.



## 3. Attention 메커니즘과 Seq2Seq 모델의 문제 해결

기존의 **RNN/LSTM 기반 Seq2Seq 모델**은 입력 문장이 길어질 때 치명적인 문제가 있었습니다.

* **Seq2Seq의 문제 (정보 손실 및 기울기 소실):** 인코더가 모든 입력 단어의 정보를 고정된 크기의 단일 벡터(Context Vector) 하나로 압축해야 합니다. 이로 인해 문장이 길어지면 초기 정보가 유실되는 병목(Bottleneck) 현상이 발생합니다.
* **Attention의 해결책:** 디코더가 단어를 예측할 때, 하나의 압축된 컨텍스트 벡터에만 의존하지 않습니다. 대신 **인코더의 모든 출력(Hidden states)을 매 스텝마다 다시 참고**합니다. 이때 입력 문장의 어떤 단어가 현재 예측할 단어와 가장 연관성이 높은지 '주의(Attention) 가중치'를 계산하여 핵심 정보에만 집중(Focus)함으로써 긴 문장에서도 정확도를 획기적으로 끌어올렸습니다.

## 4. Transformer 모델과 Seq2Seq 구조의 근본적인 차이점

Transformer는 Attention 메커니즘만을 사용하여 설계된 모델로, 기존 RNN 기반 Seq2Seq의 한계를 완벽히 극복했습니다.

* **순차적 처리(RNN)의 탈피:** 기존 Seq2Seq는 단어를 순차적으로(시간 흐름에 따라) 입력받아 처리해야 했기 때문에 연산 속도가 느렸습니다. 반면, Transformer는 RNN이나 CNN을 완전히 배제하고 셀프 어텐션(Self-Attention)만을 사용하여 문장 내 모든 단어를 **동시에 병렬로 연산**합니다.
* **위치 인코딩(Positional Encoding) 도입:** 데이터를 병렬로 한 번에 입력받기 때문에 단어의 순서 정보를 잃게 됩니다. 이를 해결하기 위해 단어의 임베딩 벡터에 위치 정보를 더해주는 Positional Encoding 기법을 사용합니다.
* **전역적인 문맥 파악 (Global Receptive Field):** 단어 간의 거리가 멀어도 셀프 어텐션을 통해 한 번의 계산만으로 두 단어의 관계(문맥)를 직접적으로 연결하고 파악할 수 있어 장기 의존성(Long-term dependency) 문제를 탁월하게 해결합니다.
