# 위클리 페이퍼 #11

## BERT와 GPT, Hugging Face Transformers, 주요 사전학습 모델

## 1. BERT와 GPT의 주요 차이점

BERT와 GPT는 모두 **Transformer**를 기반으로 하지만, 구조와 학습 목적이 다르다.

### BERT

BERT는 Transformer의 **Encoder**를 사용하는 모델이다. 문장의 앞과 뒤를 동시에 참고하는 **양방향 문맥 학습**을 통해 단어와 문장의 의미를 이해한다.

대표적인 학습 방식은 문장의 일부 단어를 가린 뒤 원래 단어를 예측하는 **Masked Language Modeling**이다.

예를 들어 `대한민국의 수도는 [MASK]이다`라는 문장에서 `[MASK]`에 들어갈 ‘서울’을 예측하면서 문맥을 학습한다.

BERT는 새로운 문장을 생성하기보다는 입력된 문장을 분석하고 이해하는 작업에 적합하다.

* 문서 및 뉴스 분류
* 긍정·부정 감성 분석
* 개체명 인식
* 스팸 및 악성 댓글 탐지
* 검색 및 추출형 질의응답

### GPT

GPT는 Transformer의 **Decoder**를 사용하는 모델이다. 앞에서 입력된 단어를 바탕으로 다음에 올 단어를 순서대로 예측한다.

예를 들어 `오늘 날씨가 매우`라는 문장이 입력되면, 다음에 올 가능성이 높은 `좋다`와 같은 단어를 생성한다. 이 과정을 반복하여 문장과 문단을 만든다.

GPT는 **자연어 생성**에 강하며, 다음과 같은 분야에 적합하다.

* 챗봇과 대화형 AI
* 이메일, 보고서 및 콘텐츠 작성
* 문서 요약과 번역
* 질의응답
* 코드 생성
* 아이디어와 시나리오 작성

### 핵심 비교

| 구분     | BERT                | GPT                 |
| ------ | ------------------- | ------------------- |
| 기본 구조  | Transformer Encoder | Transformer Decoder |
| 문맥 처리  | 문장 앞뒤를 동시에 분석       | 앞의 단어만 참고           |
| 주요 목적  | 언어 이해와 분석           | 언어 생성               |
| 학습 방식  | 가려진 단어 예측           | 다음 단어 예측            |
| 적합한 분야 | 분류, 감성 분석, 정보 추출    | 대화, 글쓰기, 요약, 코드 생성  |

즉, **BERT는 “이 문장이 무엇을 의미하는가”를 분석하는 데 강하고, GPT는 “다음에 어떤 내용이 와야 하는가”를 생성하는 데 강하다.**

## 2. Hugging Face Transformers 라이브러리

Hugging Face Transformers는 BERT, GPT, T5, BART 등 다양한 사전학습 모델을 쉽게 사용할 수 있도록 지원하는 **오픈소스 AI 라이브러리**이다.

개발자는 모델을 처음부터 직접 구현하거나 학습하지 않고, 공개된 사전학습 모델을 불러와 바로 추론하거나 자신의 데이터로 추가 학습할 수 있다.

주요 기능은 다음과 같다.

* 사전학습 모델과 토크나이저 불러오기
* 텍스트 분류, 생성, 번역, 요약, 질의응답 수행
* 특정 업무 데이터에 맞춘 파인튜닝
* PyTorch 기반 모델 학습과 평가
* Hugging Face Hub를 통한 모델 검색과 공유
* 자연어뿐 아니라 이미지와 음성 모델 지원

특히 `pipeline()` 기능을 사용하면 복잡한 모델 구조를 잘 모르더라도 간단한 코드로 감성 분석이나 문장 생성 기능을 구현할 수 있다.

따라서 Hugging Face Transformers는 최신 AI 모델을 연구하거나 실제 서비스의 프로토타입을 빠르게 제작할 때 매우 유용하다.

## 3. BERT와 GPT 이후의 주요 사전학습 모델

BERT와 GPT 이후에는 성능, 학습 효율, 모델 크기와 생성 능력을 개선한 다양한 모델이 등장했다.

### RoBERTa

BERT의 구조는 유지하면서 더 많은 데이터와 개선된 학습 방법을 적용한 모델이다. 문서 분류, 자연어 추론, 감성 분석 등에서 BERT보다 향상된 성능을 보였다.

### DistilBERT

지식 증류 기술을 이용해 BERT를 더 작고 빠르게 만든 경량 모델이다. 성능을 비교적 잘 유지하면서도 추론 속도가 빨라 모바일이나 실시간 서비스에 적합하다.

### ELECTRA

가려진 단어를 맞히는 대신, 문장 속 단어가 원래 단어인지 다른 단어로 교체된 것인지를 판별한다. BERT보다 효율적으로 학습할 수 있다는 장점이 있다.

### T5

모든 NLP 작업을 **텍스트 입력 → 텍스트 출력** 형태로 통일한 Encoder-Decoder 모델이다. 번역, 요약, 분류, 질의응답 등 다양한 작업을 하나의 구조로 처리할 수 있다.

### BART

BERT의 양방향 Encoder와 GPT의 생성형 Decoder를 결합한 모델이다. 손상된 문장을 원래 문장으로 복원하는 방식으로 학습하며, 특히 문서 요약과 텍스트 생성에 강하다.

### LLaMA

Meta가 개발한 Decoder 기반 대규모 언어 모델이다. 비교적 효율적인 구조와 높은 성능을 바탕으로 대화형 AI, 문서 작성, 코드 생성과 자체 AI 서비스 구축에 폭넓게 활용되고 있다.

---

## 4. 결론

BERT와 GPT는 같은 Transformer에서 출발했지만 사용 목적이 다르다. BERT는 문장의 전체 문맥을 분석하므로 분류와 정보 추출에 적합하고, GPT는 다음 단어를 연속적으로 예측하므로 대화와 콘텐츠 생성에 적합하다.

Hugging Face Transformers는 이러한 사전학습 모델을 쉽게 불러오고 학습하거나 활용할 수 있게 해주는 대표적인 라이브러리이다.

실제 NLP 프로젝트에서는 모델의 성능만 비교하기보다 작업 목적에 맞게 모델을 선택해야 한다. 문장 이해와 분류에는 BERT 계열, 자유로운 문장 생성에는 GPT와 LLaMA 계열, 번역과 요약 같은 텍스트 변환에는 T5와 BART 계열이 적합하다.
