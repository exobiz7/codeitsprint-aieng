# real Copy-Paste 증강 가이드 (Codex, Mac Studio)

> **한 줄 원칙:** 실제(fold0-train) 도메인 통계를 **그대로 재현(match)** 하라. 새 분포를 **창작(impose)하지 마라.**
> (균일 클래스 밸런싱을 강제했던 직전 synth2500이 오히려 점수를 떨어뜨렸다. 그 실수를 반복하지 않는다.)

## 0. 목적 & 맥락
- 대회 데이터(캐글 기본제공)의 **real 알약을 잘라 새 조합으로 재합성**하는 in-domain 증강(레버 b, "리얼 Copy-Paste").
- 목적은 **희소 클래스 커버리지가 아니라**(그건 AI Hub synth의 역할) **in-domain 물량 증대 + real:synth 비율 회복**이다.
- 따라서 **자연 편중 분포를 유지**하는 것이 맞다. 억지로 고르게 만들지 않는다.

## 1. 입력 (Mac Studio 경로)
| 자산 | 경로 |
|---|---|
| 소스 이미지 폴더 | `/Volumes/SSD 4T/01_sprint_ai_project1_data/train_images/` (평면, 976×1280 PNG) |
| **소스 매니페스트** | `realcopy_source_manifest_fold0train.json` (이 폴더에 동봉 → Studio로 복사) |
| **categories 스키마** | `target_categories_schema.json` (56클래스, 출력에 그대로 사용) |
| 출력 위치 | `/Volumes/SSD 4T/01_sprint_ai_project1_data/processed/kaggle_realcopy_v1_1500/` |

### 소스 매니페스트가 유일한 소스다 (누수 차단)
- 매니페스트 `images[].file` + `pills[].bbox_px`(픽셀 [x,y,w,h]) + `category_id`(=dl_idx)만 사용.
- 여기엔 **fold0 train 181장만** 들어있다. **val 51장·test는 의도적으로 제외** — 다른 곳에서 알약을 가져오면 평가 누수가 발생하니 절대 금지.
- 매니페스트에 없는 이미지/박스는 건드리지 않는다.
- 참고 통계(매니페스트 상단에 포함): 소스 알약 597개 · 등장 49클래스 · 알약/img 2~4(평균 3.30) · 클래스별 최다 122 / 최소 3.

## 2. 파이프라인 (696에서 잘 작동한 방식 그대로)
1. **알약 컷아웃(알파 추출)** — 각 소스 이미지를 열고 `bbox_px`로 알약을 자른다. 사각 크롭이 아니라 **실루엣 알파**가 필요:
   - 불투명 정제: 휘도 Otsu + 모폴로지 + 컨투어 → 마스크
   - 반투명 연질캡슐(저대비): SAM2(prompt="pill") → 마스크
   - 라우팅: CV 품질 게이트 통과분은 CV, 실패분만 SAM2
   - 경계 **1–2px 침식**(연회색 fringe 제거)
   - class = 그 박스의 `category_id` (그대로, 재판정 없음)
2. **배경 생성** — fold0-train 이미지의 **빈 연회색 영역**을 크롭·타일링해 976×1280 배경 생성.
   - ⚠️ **과거 버그 재발 방지:** 배경 패치에 알약이 섞이면 안 된다. 반드시 그 이미지의 **모든 `bbox_px` 영역을 마스킹**하고, 박스와 겹치지 않는 영역에서만 배경을 샘플링할 것. 생성 후 "배경 알약 혼입 0" 자체검증 필수.
3. **배치(구성)** — 배경 위에 알약 2~4개 배치(§3 규칙):
   - **비겹침 그리드**(테스트 저오클루전 매칭), 알약 간 간격 유지
   - 알약별 **완만한 기하 변형만**: 회전 자유(평면 회전은 OK), 스케일 ±10% 내외, **앞면 유지**(뒤집기·원근 왜곡 금지), 약한 그림자
4. **합성 & 라벨** — 알파 컴포지트 → 전역 bbox 산출 → COCO/YOLO 라벨. `category_id = dl_idx`.

## 3. 분포 규칙 (★ 부작용 방지의 핵심)
- **클래스 분포:** 매니페스트의 `class_count_natural` 자연 편중을 **그대로 따른다**. 즉 소스 알약을 **자연 빈도대로 샘플링**(122개인 클래스는 자주, 3개인 클래스는 드물게 등장). **균일화·클래스 상한/하한 강제 절대 금지.**
  - 이렇게 하면 희소 클래스의 소수 인스턴스가 수십 번 반복되는 과적합도 **자동으로** 방지된다(자연 빈도라 애초에 적게 뽑힘).
- **알약 수/이미지:** 2~4개, 평균 ≈ 3.3에 맞춘다(real과 동일). 억지로 4개로 채우지 않는다.
- **bbox 크기:** real 범위 유지(정규화 면적 대략 0.02~0.12, 중앙값 ≈ 0.04). 소스 알약의 원본 크기 비율을 크게 벗어나지 않게.
- **같은 물리 인스턴스의 픽셀-동일 복붙 금지:** 재사용은 불가피하나 매 배치 완만한 기하 변형으로 완화(단, §2-3 범위 내, 도메인 이탈 금지).

## 4. 하지 말 것 (금지 목록)
- ❌ **클래스 균일 밸런싱 / 인위적 분포 강제** (직전 실패 원인)
- ❌ val/test 또는 매니페스트 밖 이미지에서 알약·배경 추출 (누수)
- ❌ 배경에 알약이 남은 패치 사용
- ❌ 강한 색/WB/밝기 변형, HSV 왜곡 — real은 이미 in-domain이므로 **색 보존**(정규화 최소·불필요). 도메인을 바꾸지 말 것
- ❌ 뒤집기·심한 원근/어파인, 과도한 겹침·오클루전
- ❌ 금지셋 `TL_2_조합` / `TS_2_조합` 관련 데이터
- ❌ 알약 없는 배경-only 이미지 생성(모든 출력은 2~4알 포함)

## 6. 자체 검수 리포트 (reports/에 저장, 생성 직후 실행)
1. **클래스 분포 비교** — 생성물 클래스 빈도 vs 매니페스트 `class_count_natural`. 순위상관/편차가 작아야 함(자연 편중 재현 확인). *균일에 가까우면 실패 신호.*
2. **알약/img 분포** — 2~4, 평균 3.2~3.4 확인.
3. **bbox 정규화 면적 분포** — real 범위(≈0.02~0.12) 내 확인.
4. **배경 알약 혼입 검사** — 배경 패치가 모두 pill-free였는지 카운트 = 0.
5. **좌표 유효성** — 모든 bbox가 이미지 경계 내(위반 0), 클래스 ∈ 56.
6. **육안 샘플 20장** PNG 컨택트시트 저장.

## 7. 완료 후 회신
생성 폴더 경로 + §6 리포트 요약(클래스 분포 그래프/표, 알약수·bbox 통계, 위반 카운트)을 함께 전달할 것.
검수는 우리(맥북) fold0 동일 harness로 애블레이션해 판단한다.
